# 📚 API REST - Biblioteca Digital (Digital Library API)

API REST desarrollada en Node.js, Express y TypeScript, utilizando Mongoose para la conexión y gestión de una base de datos NoSQL en MongoDB. El proyecto implementa una arquitectura modular basada en Modelos, Controladores y Enrutadores (MVC).

## 🚀 Tecnologías Utilizadas
* **Node.js**: Entorno de ejecución para JavaScript/TypeScript en el servidor.
* **Express**: Framework minimalista para la creación de servidores web y rutas.
* **TypeScript**: Superset de JavaScript que aporta tipado estático y mayor robustez.
* **Mongoose**: ODM para modelar los datos y conectarse a MongoDB.
* **ts-node-dev**: Herramienta de desarrollo para recompilar y reiniciar el servidor en tiempo real.
